========================================
15. RESPONSIVE DESIGN
========================================

Mobile responsiveness is extremely important.

The reference website is primarily viewed
on a mobile phone.

On mobile:

- Use a hamburger navigation.
- Stack sections vertically.
- Make buttons comfortably tappable.
- Maintain generous vertical spacing.
- Keep headings large and readable.
- Ensure cards occupy the available width.
- Prevent horizontal scrolling.
- Maintain consistent side padding.

On desktop:

- Expand the layout intelligently.
- Use multi-column service card layouts.
- Increase hero typography.
- Introduce more whitespace.
- Keep the same editorial aesthetic.

========================================
16. ANIMATIONS AND INTERACTIONS
========================================

Use subtle, tasteful animations.

Include:

- Smooth scrolling.
- Gentle fade-in animations.
- Subtle upward movement as sections enter view.
- Smooth navigation transitions.
- Elegant button hover effects.
- Subtle card hover effects.

Avoid excessive animations.

The website should feel refined, not flashy.
